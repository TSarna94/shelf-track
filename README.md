# Shelf Track

## Overview

Shelf Track is a command-line bookstore inventory management system built with Python and SQLite. The application allows users to manage books and authors through a relational database structure while providing inventory reporting and search functionality.

The project demonstrates database design, SQL queries, CRUD operations, data relationships, and Python application development.

## Features

### Book Management

- Add new books
- Update existing book records
- Delete books from inventory
- Search books by ID, title, or author

### Author Management

- Add new authors
- Update author information
- Delete authors
- View all stored authors

### Inventory Reporting

- Full inventory reports
- Book and author relationship reporting
- Search books with author information
- Enhanced inventory lookup using SQL joins

### Database Features

- SQLite relational database
- Multiple related tables
- Foreign key support
- Seed data for testing

## Technologies Used

- Python 3
- SQLite3
- SQL
- Command-Line Interface (CLI)

## Database Structure

### Book Table

| Field | Description |
|---------|-------------|
| id | Book ID |
| title | Book title |
| authorID | Related author ID |
| qty | Quantity in stock |

### Author Table

| Field | Description |
|---------|-------------|
| id | Author ID |
| name | Author name |
| country | Author country |
